홈 화면에 추가해 앱처럼 쓰기

웹 브라우저로 여는 앱은 설치 없이 바로 쓸 수 있습니다. 홈 화면에 추가해 두면 다른 앱처럼 아이콘을 눌러 열리고, 브라우저의 주소창 없이 화면을 온전히 씁니다.

앱 열기

안드로이드 · 크롬삼성·LG 등 안드로이드 휴대폰과 태블릿

  1. 크롬에서 앱을 엽니다.
  2. 오른쪽 위 점 세 개 메뉴를 누릅니다.
  3. 「홈 화면에 추가」 또는 「앱 설치」를 고릅니다.
  4. 이름을 확인하고 「추가」를 누르면 홈 화면에 아이콘이 생깁니다.

안드로이드 · 삼성 인터넷갤럭시의 기본 브라우저

  1. 삼성 인터넷에서 앱을 엽니다.
  2. 아래 줄 세 개 메뉴를 누릅니다.
  3. 「현재 페이지 추가」를 누르고 「홈 화면」을 고릅니다.
  4. 「추가」를 누르면 홈 화면에 아이콘이 생깁니다.

아이폰 · 아이패드 · 사파리애플 휴대폰과 태블릿

  1. 사파리에서 앱을 엽니다.
  2. 아래 가운데 공유 단추(네모에서 화살표가 위로 나가는 모양)를 누릅니다.
  3. 목록을 내려 「홈 화면에 추가」를 고릅니다.
  4. 오른쪽 위 「추가」를 누르면 홈 화면에 아이콘이 생깁니다.

아이폰의 크롬에서도 같은 공유 단추로 「홈 화면에 추가」할 수 있습니다.

추가한 뒤에는

홈 화면의 아이콘으로 열면 앱처럼 전체 화면으로 열립니다. 인터넷이 없어도 열리고, 새 판이 나오면 앱 안에서 알려 줍니다.
